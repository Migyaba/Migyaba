### 💼 Expérience fintech

**BFT Group** : écosystème de paiements instantanés pour la zone UEMOA
- Hub **Mojaloop** : back-office de gestion des DFSP et des règlements (Frappe), portail d'onboarding DFSP (React + TypeScript)
- Microservices de règlement : [external-settlement-service](https://github.com/Migyaba/external-settlement-service) et [log-audit-settlement-matrix](https://github.com/Migyaba/log-audit-settlement-matrix)
- **SDK Python PI-SPI** : intégration de l'API Business de la BCEAO, avec réception des paiements entrants par webhook
- Serveur SSO **OpenAuth** (Django + Keycloak), générateur de formulaires JSON dynamiques, scoring, core banking, lutte anti-blanchiment (AML)

**AlphaConnect Technology** : plateformes de paiement
- **PayByUs** : architecture microservices (auth, utilisateurs, cartes, notifications) avec Keycloak et RabbitMQ
- **AlphaPay** : console d'administration, espace marchand, liens de paiement, checkout

**Open source** : contributions à [Mojaloop](https://github.com/mojaloop) (`central-services-shared`, `tpp-api-svc`, `ml-testing-toolkit`)
